## Personalized header

The previous Page header with an oversized app title is replaced by a Dashboard-specific header:

1. A small gold rule and **MY OJT COMPANION** label.
2. Existing Profile navigation shortcut and a 72 dp BSIT logo in the upper row.
3. The saved student name as a full-width, 36 sp display heading.
4. **Your OJT progress at a glance** as secondary text.

`state.profile.displayName` is the sole name source, observed through the existing repository/ViewModel UI state. The header does not remember a separate name or hardcode a person. Display-only leading/trailing whitespace is trimmed; stored data is not changed. Saving a Profile name updates the existing state and the next Dashboard composition displays it.

An empty or whitespace-only name displays **Welcome!** with **Set up your profile**. A saved name retains a **Profile** shortcut. Both use the existing `onProfile` callback and existing Profile route.

The name occupies a separate row below the logo rather than a constrained column beside it. It has no fixed height, max-line limit or ellipsis. Normal text wrapping plus heading line breaking allows long names and larger font scales to expand vertically without competing with the logo. The whole Dashboard scrolls. The upper label/action column has flexible width, while the logo stays square at 72 dp. The name has heading accessibility semantics; the decorative gold rule has no accessibility node.

Completed hours use the existing 28 sp headline style instead of the previous 36 sp display style, keeping the student's name the strongest text. No numeric values, progress calculation, rounding or completed-hours rules were changed.

## Launcher icon

The prior launcher was the generic teal `ic_companion` vector. The manifest now references `@mipmap/ic_launcher`, an adaptive icon using a warm neutral background and the supplied, unmodified logo as a separate foreground bitmap. The previous vector remains in the project; no app label or application ID changes accompany the icon update. The app's existing minimum API is 26, so the adaptive resource covers supported devices.

Foreground insets are 25% on each side. On the standard 108 dp layer this allocates a centered 54 dp square to the original square PNG, preserving all artwork and transparency. A source-alpha geometry check measured the furthest nontransparent pixel at approximately **29.13 dp** from the icon center after scaling, inside a conservative 33 dp radius. This protects details when launcher masks are applied. The foreground uses bitmap filtering for scaling and no custom crop mask.

The separate layers and padding follow [Android adaptive icon guidance](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive), which describes 108 dp layers and a protected 66 dp central region. No recolored monochrome version is supplied. Device launchers may still apply user-requested icon theming, particularly on newer Android releases, and may cache the previous icon temporarily; this is outside app-controlled logo pixels. OEM mask/rendering behavior still needs device validation.

## Samsung Galaxy A06 validation checklist

Use a normal signed update over the installed app, preserving data. Do not uninstall or clear data. Use a separate test installation/profile for blank and synthetic long-name cases if changing the real Profile is undesirable.

- [ ] Open Dashboard with an existing saved Profile name. Verify MY OJT COMPANION is small, the name is the largest text, and the subtitle matches the design.
- [ ] Open Profile through the header shortcut, change/save the name, return to Dashboard, and verify the saved value appears. Restart normally and verify it is loaded again.
- [ ] Test an empty name and whitespace-only name: Welcome! and Set up your profile must appear, and the shortcut must reach the existing Profile screen.
- [ ] Test a multi-part name near the existing 100-character limit, including a long unbroken component. Verify wrapping without ellipsis, overlap or horizontal scrolling.
- [ ] Repeat at default and maximum supported font/display scaling, portrait and landscape, including a narrow-window configuration. Verify the full name, logo, Profile shortcut and lower content remain reachable by vertical scrolling.
- [ ] Verify the 72 dp logo retains its proportions, full badge, original colors and transparent edges. Confirm it remains legible against both theme backgrounds.
- [ ] Switch System Default, Light and Dark in Profile and revisit Dashboard. Verify text contrast, original logo colors, maroon progress hero, status/empty states and existing theme persistence.
- [ ] Confirm progress, completed/required/remaining hours, today's attendance and recent activities match the pre-update records. Exercise the existing attendance/activity navigation actions.
- [ ] With TalkBack, verify the name is a heading, the logo has its BSIT description, Profile is actionable, and the decorative gold rule is not announced.
- [ ] Inspect the updated icon in Samsung Home, app drawer, app settings and overview. Verify the badge is centered and its top squares/bottom star remain inside the mask. Check available launcher shapes/themed-icon options without expecting the fine caption to be readable at icon size.
- [ ] If the old icon is cached, allow a normal launcher refresh or phone restart; do not clear launcher/app storage or uninstall to force it.
- [ ] Verify the unchanged app label, retained attendance/photos/activities, widget contents/shortcuts, camera capture/review and backup interfaces remain functional.

## Limitations

The logo's fine caption is inherently small at 72 dp and at launcher scale. Source pixels are preserved rather than simplifying the artwork. Launcher masks, system icon theming and cache timing vary by device. No new profile-photo feature is provided because the existing Profile does not store one. Device layout and accessibility checks remain pending.
