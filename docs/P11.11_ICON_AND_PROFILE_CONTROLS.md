# P11.11 — Transparent launcher icon and editor-only photo controls

## Changes

Main Profile is view-only for photos: it displays the circular saved avatar, student information, Edit profile and Settings. No Change Photo/Remove Photo callbacks, picker registration or photo dialog remain on that route. The avatar has no click action.

Edit Profile now owns a Profile photo card with the current avatar, Change Photo and Remove Photo. The picker and crop dialog are scoped to the editor route. Leaving the editor cancels a pending preview when no save is in progress. Removal still requires confirmation. Photo processing, atomic private-file storage, reactive Dashboard synchronization and ZIP backup handling are unchanged. Profile field validation and save behavior are retained. Photo confirmation is independent of the Save profile button, as in P11.10, and is explained in the card.

## Original logo and transparency

Source: the original user-supplied `BSIT.png`. Its SHA-256 is `c97a6cc550c2bf22f3047810b1637fb8b2770f186e998da77d38a50ef74300e6`, identical to the existing in-app BSIT crest. The in-app image was not modified.

The launcher-only copy losslessly trims fully transparent margins (alpha bounds 95,40–1021,936), then centers the complete 926×896 crop on a transparent 926×926 square. All cropped RGBA pixel values are preserved. Adaptive foreground inset is 23.4%, calculated from every nontransparent pixel to retain the entire artwork inside a 65dp safe diameter on Android's 108dp foreground layer. Both adaptive backgrounds now use `@android:color/transparent`. The unused warm-white launcher background color was removed. Transparent regular and round legacy fallback PNGs are supplied at mdpi through xxxhdpi. No decorative square, circle or background was baked into any logo asset.

Name remains OJT Companion. Application ID remains `com.lazarus.personalojtdtr`.

## Samsung verification and limitation

Installed in place on authorized Samsung Galaxy A06 (SM-A065F). The home-screen icon no longer shows the old white container; the full crest is visible. The home wallpaper is black, so this observation alone cannot prove that every Samsung surface preserves alpha.

Samsung Finder's suggested-apps panel renders a black rounded backing even though the installed adaptive background is verified transparent by a device test. This is an observed Samsung rendering limitation for this icon configuration. No black backing was added to app resources. Container-free rendering on every launcher/system surface is not guaranteed; launcher settings were not changed.

Profile and Edit Profile were inspected on the device. Generated-image light/dark screenshots show readable cards and photo controls without clipping. Tests assert the main avatar cannot be clicked, controls exist only after opening the editor, preview cancellation does not confirm, removal requires confirmation, and Dashboard displays the same avatar reference.
